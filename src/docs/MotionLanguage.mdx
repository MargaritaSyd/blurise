# Motion language

blurise is a small cinematic vocabulary. Components are the vehicle; this language is the product.

## Enter

### Blur rise

Enter with **opacity**, **blur**, and **translateY**.

```tsx
import { BlurRise } from 'blurise';

<BlurRise>…</BlurRise>
<BlurRise inView>…</BlurRise>
```

- Class: `.br-rise` → `.br-rise-active`
- Tokens: `--br-duration-rise`, `--br-blur-from`, `--br-rise-from`

### Blur fade

Blur + opacity only — no translate. Useful for overlays and type.

```tsx
import { BlurFade } from 'blurise';

<BlurFade>…</BlurFade>;
```

- Class: `.br-fade` → `.br-fade-active`

### Scale rise

Rise plus a soft scale from `--br-scale-from` (default `0.96`).

```tsx
import { ScaleRise } from 'blurise';

<ScaleRise>…</ScaleRise>;
```

- Class: `.br-scale-rise` → `.br-scale-rise-active`

### Slide

Directional slide + opacity (no blur).

```tsx
import { Slide } from 'blurise';

<Slide from="up">…</Slide>
<Slide from="left" inView>…</Slide>
```

- `from`: `up` | `down` | `left` | `right`
- Class: `.br-slide.br-slide--{from}` → `.br-slide-active`
- Token: `--br-slide-from`

### Clip wipe

Directional reveal with `clip-path` — more cinematic than a plain slide.

```tsx
import { ClipWipe } from 'blurise';

<ClipWipe from="left">…</ClipWipe>
<ClipWipe from="up" inView>…</ClipWipe>
```

- `from`: `up` | `down` | `left` | `right`
- Class: `.br-wipe.br-wipe--{from}` → `.br-wipe-active`

Under `prefers-reduced-motion`, all enters become opacity-only (`br-rise-reduced`).

## Exit

### Blur fall

Inverse of rise: blur, drop, and fade out when `active` is true.

```tsx
import { BlurFall } from 'blurise';

<BlurFall active={leaving} onAnimationEnd={unmount}>
  …
</BlurFall>;
```

- Class: `.br-fall` → `.br-fall-active`
- Reduced motion: opacity-only (`br-fall-reduced`)

## Stagger

Cascade child delays with `--br-i` and `--br-stagger-gap`.

```tsx
import { BlurRise, Stagger } from 'blurise';

<Stagger gap={80}>
  <BlurRise>One</BlurRise>
  <BlurRise>Two</BlurRise>
  <BlurRise>Three</BlurRise>
</Stagger>;
```

Works with any enter primitive (`BlurFade`, `ScaleRise`, `Slide`, …).

## Grain

A tiled SVG turbulence overlay. **Texture, not motion.**

```tsx
import { Grain } from 'blurise';
// or
<Card grain>…</Card>;
```

## Idle float

A slow translate / rotate loop. Do **not** float dialogs or menus.

```tsx
import { Float } from 'blurise';
// or
<Card float>…</Card>;
```

## Breathe

Soft scale pulse. Prefer this over `Float` when another transform already owns translate.

```tsx
import { Breathe } from 'blurise';

<Breathe>…</Breathe>;
```

- Class: `.br-breathe`
- Tokens: `--br-breathe-scale`, `--br-breathe-duration`
- Do not nest `Breathe` and `Float` on the same node

## Shimmer

Sweeping highlight for skeletons / loading surfaces.

```tsx
import { Shimmer } from 'blurise';

<Shimmer>…</Shimmer>;
```

- Class: `.br-shimmer`
- Tokens: `--br-shimmer-duration`, `--br-shimmer-opacity`
- Override with `opacity` on `Shimmer`

Float, breathe, and shimmer all stop under `prefers-reduced-motion`.

## Composition

Put transform animations on **separate wrappers** so enter and idle do not fight:

```tsx
<Stagger gap={90}>
  <ScaleRise>
    <Breathe>
      <Grain>
        <article>…</article>
      </Grain>
    </Breathe>
  </ScaleRise>
</Stagger>
```

## Overlay motion

Dialog panels and menus use a **short** blur-rise. Backdrops only fade. Toasts rise once into the viewport.

See **Motion / Primitives**, **Motion / Enter exit**, and **Motion / Idle** for interactive demos.
